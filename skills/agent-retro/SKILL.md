Read the admitted question, pinned Agent Improvement policy, sanitized evidence
index and prior decisions. Reuse supplied citations; name missing information.
The policy's sampling/time/byte ceilings remain binding. Loading this method
permits no additional sampling, provider logs, other workdirs or access expansion.

Inspect navigation difficulty, deterministic checks and wiring, instruction
ambiguity/duplication/no-ops, tool economy, missing information and repeated
handoff/correction patterns. Prefer an existing check to another always-loaded
instruction. Compare successful cases and counterexamples.

Separate observations, causal hypotheses, confounders and contrary evidence.
A missing check becomes a candidate only with relevant evidence. Rank at most
two proposals by full-process token savings and autonomy hypotheses, including
all-agent overhead and collateral ordinary-General costs. Worker savings alone
do not establish benefit. Keep safety, correctness, access and ownership intact.

Use the canonical fingerprint and proposal/evaluation templates. Return complete
proposals or no-change/incomplete with citations, gaps and next owner. General
cannot approve or implement its own suggestions. Instruction edits, deployments
and delivery work require the existing exact spec/ticket decision and routing.
