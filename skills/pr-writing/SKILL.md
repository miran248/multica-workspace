---
name: pr-writing
description: "Write a substantive PR description or revision-specific review, parent, or production decision handoff when evidence and next action require synthesis."
metadata:
  version: 0.1.0-pilot.1
---

Read the originating ticket/spec, current diff and exact PR head. Lead with the concrete problem and resulting behavior, linking approved scope and criterion-to-evidence coverage. Include appropriate before/after evidence when it helps assessment; scale prose to the change and respect the repository template.

State actual check outcomes, checks not run, unresolved risks, blockers and the next owner/action. A review fix changes the head: identify the new revision and request fresh independent acceptance rather than inheriting the old verdict. Keep implementation's own checks distinct from Reviewer acceptance.

Deliver the requested handoff to the required destination, including the squad-owned parent when required. For production decisions provide exact revision and approval packet; notification is not approval or deployment evidence. Routine short handoffs may be written directly without this skill. Complete when the recipient can take the correct next action from the handoff and linked evidence.
