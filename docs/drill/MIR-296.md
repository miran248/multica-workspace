# Drill spec — the reslice window and one PR link

Throwaway record for the MIR-289 live-acceptance drill in a throwaway project.

The reslice window is the spec PR unmerged, or merged with no child in a started status: a
change inside it is made in place, at the same PR number and head. The slice freezes at the
first started child; a real change after that is a new epic.

Revision inside the window: the changed direction is amended at the same head and PR number;
the child set is rewritten in place, never duplicated.
